<h2 align="left">Vitual Machine with Windows Server 2025 OS </h2>  
This project was built to gain hands-on, practical experience with the latest enterprise infrastructure standard by deploying and managing a Windows Server 2025 environment. The goal of this home lab was to move beyond theoretical concepts and actively configure core identity and network services from scratch, specifically focusing on Active Directory Domain Services (AD DS), DNS zone management, and automated IP allocation via DHCP. By simulating a real world infrastructure in a controlled sandbox, I developed a deeper understanding of centralized user management, network policies, and foundational system administration practices required to maintain a secure and efficient network.
